이는 기존 일일 1단위 점검을 넘어 전체 제작 문제를 수정하고 EP001~EP005 파일럿 시즌을 완성하라는 현재 작업 지시다. 기존 그림과 원본 후보는 보존한다. 작품 제작·기준선 정합성 수정은 수행하지만, 이 요청을 개별 산출물의 사전 QA 통과나 이미 완료된 release 승인으로 기록하지 않는다.

EP002는 기존 script.json의 16개 장면이 16페이지 콘티와 모두 대응한다. 서로 다른 script.md 15페이지 초안을 ID로 조회한 것이 대사 오염의 원인이다. 57개 패널 모두에 scene_number와 명시적인 텍스트/무대사 배열을 부여했다. 기존 15페이지 초안 및 교정 전 오버레이를 script/archive에 보존했다. 가족·연구실·수사 장면의 기존 JSON 대사를 해당 콘티로 배치하고 초대장/실험 노트의 필수 소품 텍스트를 명시했다.

GitHub API는 샌드박스 밖에서 정상 응답하며 열린 PR은 0개였다. 앞으로 DNS/API 실패를 곧바로 원격 장애로 단정하지 않고 허용된 네트워크 실행 경로를 확인한다.
