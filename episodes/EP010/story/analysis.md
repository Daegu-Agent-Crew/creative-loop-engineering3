# EP010 「면벽하지 않는 자들」 — 원안 분석

## 범위와 로그라인

원안의 S2E05 「면벽하지 않는 자들」 반전 구조만 각색한다. EP009에서 왕먀오가 남긴 경계 입력 시험 카드 세 장은 게임 엔진의 취약점 가설이며 가속기에서의 효과는 미검증이다. 데이터를 모두 볼 수 있는 소페르 앞에서 왕먀오 일행은 계획을 숨기는 대신 서로 모순된 과학적 행동을 동시 실행한다. 감시점 아래 세 카드의 그림자가 갈라지는 이미지는 '벽 없이 면벽하기'라는 역설을 보여 준다. 청신의 딸 양동은 어머니의 미완 실험, 곧 인류 쪽 버그 리포트 초고의 빠진 대조 조건을 가져온다.

## 핵심 사건

| 사건 | 감정 무게 |
|---|---:|
| EP009의 세 시험 카드가 현실 시험 계획으로 넘어온다. | 3 |
| PDC 책임자가 하나의 명확한 가설만 요구하며 병렬 계획을 막는다. | 4 |
| 안전 중단선과 독립 대조군을 둔 제한적 동시 시험이 허용된다. | 3 |
| 세 시설의 상반된 행동에 위조 출력의 보정 지연이 잠깐 갈라진다. | 4 |
| 소페르의 보정이 다시 수렴하여 승리 해석이 무너진다. | 5 |
| 양동이 청신의 미완 보고서와 빠진 대조 판정을 제시한다. | 5 |
| 세 사람은 관찰 가능한 보정 선택만 검증하는 다음 시험을 준비한다. | 4 |

## 테마·인과의 경계

- 감시자는 행동을 볼 수 있지만 관찰만으로 사람의 목적을 직접 읽지는 못한다. 다만 반복된 데이터에서 의도를 **추정할 수 있으므로**, 이번 화는 소페르가 영원히 속는다는 증명이 아니다.
- 과학적 정직함은 단일 행동을 고집하는 일이 아니라, 복수의 입력과 독립된 판정 규칙을 분리하는 일이다.
- 병렬 행동의 효과는 관찰 가능한 위조 출력의 보정 선택 변화로 한정한다. 진짜 물리 데이터는 S2E06의 사건으로 남긴다.

## 캐릭터 아크

| 인물 | 시작 → 끝 | Want | Need | Moral Need / 변화 트리거 |
|---|---|---|---|---|
| 왕먀오 | 검증 가능한 단일 가설에 매인 연구자 → 병렬 입력과 단일 판정의 설계자 | EP009 세 카드의 현실 검증 | 설명 가능한 기준을 유지한 채 전술을 바꾸기 | 명료함을 이유로 협업의 다른 질문을 지운다. PDC의 요구와 양동의 대조 조건이 바꾼다. |
| 스치친 | 감시 앞의 냉소적 호위 → 안전 중단과 사람의 선택을 지키는 동료 | 팀이 살아서 다음 시험에 도달 | 농담 뒤의 책임을 맡기 | 과학을 남의 일로 치부한다. 중단 손잡이를 맡으면서 달라진다. |
| 양동 | 어머니의 수첩을 홀로 간직한 상속자 → 미완의 질문을 공동 실험의 기준으로 건네는 연구자 | 초고를 유효한 시험으로 잇기 | 유산을 완성품처럼 다루지 않기 | 어머니의 이름 뒤에 숨을 유혹. 빠진 대조 조건을 먼저 고백한다. |
| PDC 책임자 | 단일 가설과 안전만 승인 → 제한된 병렬 시험을 조건부 허용 | 통제 가능한 검증 | 모순된 입력도 엄격하게 기록 가능함 인정 | 도장과 중단선을 통한 제도적 상대. |
| 소페르 | 완벽한 관찰자로 보임 → 분류를 바꾸는 적응 시스템으로 드러남 | 위조 출력의 일관성 유지 | 해당 없음 | 인간형 얼굴 없음. 붉은 보정 파형으로만 나타난다. |

양동의 자기 인식은 “어머니가 답을 남긴 게 아니라 질문의 순서를 남겼다”이다. 청신은 EP001의 70대 노과학자 모습으로만, 세피아 회상에 등장한다. 어머니의 생사나 최종 의도는 새로 확정하지 않는다.

## 양동 외형 고정 DNA

20대 중국 여성. 가로보다 조금 긴 타원형 얼굴, 넓지 않은 이마, 완만한 광대, 작은 곧은 코, 가는 눈썹, 차분한 아몬드형 눈, 단정한 작은 입. 검은 생머리는 어깨 아래까지 곧게 내려오며 앞머리는 **본인 기준 왼쪽에서 오른쪽으로** 넘긴다. 회색 카디건을 연한 하늘색 블라우스 위에 걸치고 작은 갈색 가죽 서류가방을 손에 든다. 청신과의 유사성은 차분한 눈매와 입가의 절제된 인상으로만 표현한다. 손에 든 서류가방은 수첩의 출처를 보여 주는 소품이다. 첫 정면 얼굴은 p9-4; p8-4에서 헤어·복장·가방을 예고한다.

## Opponent 구조

| 상대 | 왕먀오의 약점을 찌르는 방식 |
|---|---|
| 소페르의 적응적 위조 | 하나의 목적을 고정해 읽으려는 왕먀오의 습관을 이용해 보정을 다시 수렴시킨다. |
| PDC 실험 책임자 | 설명 가능한 단일 가설만 승인하려 하여 병렬 행동의 윤리와 검증성을 묻는다. 얼굴을 새 캐릭터로 고정하지 않는다. |
| 양동의 미완 수첩 | 반대자가 아니라 왕먀오의 성급한 완결 욕구를 흔드는 거울이다. |

## 가설과 재미

주 가설은 H6(미스터리 강도): p1의 세 갈래 그림자, p8의 일시적 갈라짐, p9의 재수렴, p10의 미완 수첩으로 질문을 단계별 전환한다. 부 가설 H5(시각적 압도와 여백): p1·7·11·15의 무언 풀페이지를 4컷 페이지 사이에 둔다. H2는 과학 설명 p3~8과 모녀 유산 p9~13의 체류를 비교한다. H1은 p14~15의 다음 시험 약속이 복귀를 유도하는지 본다. 측정 변수는 페이지별 체류·이탈·다음 화 복귀율이며 실제 수치는 아직 없다.

| 재미 요소 | 목표 감정 | 시각 표현 |
|---|---|---|
| ③ 과학적 패러다임 붕괴 | 모순이 결함이 아니라 도구가 되는 쾌감 | 반대 방향의 다이얼과 단일 판정 삼각형 |
| ⑤ 소페르 감시 공포 | 모든 손을 보는 붉은 점의 압박 | 모든 실험 화면에 동일한 작은 붉은 원 |
| ⑥ 인간 드라마 | 모녀 사이의 미완성을 이어 받는 조용한 존중 | 세피아 수첩에서 청회색 대조 판으로 전환 |
| ⑦ 퍼즐 | 갈라진 보정이 왜 다시 합쳐졌는지 궁금증 | 세 줄의 분리·수렴 파형, 정확한 표기는 후처리 |

원작 독립적 재해석이다. 원작 면벽의 은폐 전략을 예고하면서, 이 화는 은폐 대신 공개된 상반 행동과 검증 가능한 노이즈를 사용한다.
