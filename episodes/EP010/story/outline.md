# EP010 「면벽하지 않는 자들」 — 구조 설계 (15p)

## 3막·콜드 오픈

| 막 | 페이지 | 목적 |
|---|---|---|
| 1 설정 | p1~4 | EP009의 세 카드, 감시 앞의 역설, PDC의 조건부 허가 |
| 2 갈등 | p5~11 | 동시 실행과 가짜 승리, 소페르 재수렴, 양동의 미완 수첩 |
| 3 해결·훅 | p12~15 | 청신 회상, 빠진 대조 판정의 적용, 다음 시험의 조건부 준비 |

방식은 부조화 삽입이다. 첫 컷에서 감시점 아래 놓인 세 카드의 그림자가 서로 다른 방향으로 뻗는다. 첫 세 컷 안에 EP009의 카드와 스치친의 “다른 노래”가 나온다. 이 화의 시험은 보정 지연의 분리·재수렴만 관찰한다. 실제 물리학 회복과 11분의 진짜 데이터는 S2E06의 몫이다.

## McKee Gap·미스터리

| 장면 | 기대 | 실제 결과와 변화 |
|---|---|---|
| p1~2 | 게임 카드가 곧 답 | 가속기 미검증을 인정하고 질문을 다시 설계 |
| p3~4 | 병렬이면 승인 | PDC가 단일 가설을 요구하여 검증 기준이 쟁점화 |
| p5~6 | 상반 입력은 혼란만 낳음 | 안전선과 봉인 아래 제한적 시험 가능 |
| p7~8 | 감시자가 곧바로 맞춤 위조 | 보정 지연이 갈라져 일시적 틈 발견 |
| p9~10 | 틈은 지속 | 보정 재수렴, 양동 수첩도 미완 → 중단 위기 |
| p11~12 | 빈칸은 실패 | 누락된 대조 조건 자체가 다음 질문 |
| p13~14 | 진짜 데이터를 확보해야 성공 | 보정 선택 변화만 검증하는 목적 재정의 |
| p15 | 벽을 세워야 한다 | 열린 병렬 통로를 선택하되 결과는 열어 둠 |

복선은 p1의 세 그림자와 p3의 독립 보존 장치다. 장막은 p8 양동의 가방 속 문서, p10 수첩의 빈칸이다. 전환은 p9의 재수렴과 p12~13의 “같은 입력, 다른 판정”이다. p15는 결과 공개가 아니라 다음 시험의 약속이다. H6 미스터리 강도는 p1=2, p4=2, p8=3, p9=3, p10=3, p13=2, p15=3. H5는 네 무언 페이지와 인접 다컷의 체류를 비교한다. H2는 p3~8 과학과 p9~13 유산의 체류를 비교한다. H1은 p14~15 이후 다음 화 복귀율을 본다.
