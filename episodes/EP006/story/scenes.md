# EP006 장면 작성 — S2E01 「오차의 결」 (v3)

모든 장면은 굵고 깨끗한 잉크선, 밝은 평면 셀 채색, 둥근 표현형 인물, 검은 그림자의 1980년대 토리야마 만화 미감을 쓴다. 이미지 프롬프트는 AGENTS.md의 **STYLE_BLOCK을 맨 앞에** 붙인다. 숫자·한글·UI·그래프 범례는 후처리 오버레이이며 그림에는 여백만 남긴다. Masking은 단순한 인물 얼굴과 정밀한 도표·장비 실루엣의 대비로 통일한다.

### Scene 1: 여섯 서명
- **페이지:** p1 (1p) / **장소:** 제네바 관제실 화면 속 6대륙 관제실 / **시간:** 심야 / **날씨:** 실내, 외부 불명 / **등장인물:** 6명의 익명 관제원
- **장면 목적:** 첫 컷에 부조리한 공통 지문 제시. **Gap:** 국소 장비 오류라 여김 → 통신 없는 시설이 같은 오차를 보임 (사고가 세계 규모의 질문으로 변함).
- **감정 곡선:** 집중 → 불일치 → 불길한 경이. **독자 감정:** “누가 모두에게 같은 거짓말을 했나?”
- **연출 메모:** 청색 모니터와 신호 빨강, 검은 그림자. 6분할 화면을 하나의 큰 풀페이지 구도로 묶는다. Masking은 둥근 관제원 실루엣과 날카로운 파형 대비. 게임/VR 아님.
- **가설 태그:** H5-impact, H6-2. **개념 세팅:** 동일 오차 지문, 위조 데이터.

한 관제원의 손이 자신의 장비만 가리키다, 옆 모니터의 같은 톱니 결에서 멈춘다. 여섯 손이 차례로 굳는다. 대사는 없다.

### Scene 2: 가운을 접다
- **페이지:** p2 (1p) / **장소:** 왕먀오 연구실 / **시간:** EP005 직후 새벽 / **날씨:** 창밖 잔비 / **등장인물:** 왕먀오
- **장면 목적:** 연구 포기라는 상처를 행동으로 보여 준다. **Gap:** 자료를 덮으면 끝난다고 믿음 → 6대륙 알림을 보고도 끌 수 없음.
- **감정 곡선:** 탈진 → 회피 → 불편한 호기심. **독자 감정:** 인물에 대한 염려.
- **연출 메모:** 청회색 셔츠, 큰 뿔테, 굳은 어깨. 따뜻한 스탠드 한 점만 두고 창은 차갑게. EP005 함대 돛은 렌즈의 잔상 한 조각, 새 사실처럼 그리지 않는다. Masking 사용. 왕먀오 매력 지수: 두려워하면서도 화면을 완전히 꺼버리지 않는 성실함. 게임/VR 아님.
- **가설 태그:** H2-emotion, H6-1. **개념 세팅:** 카운트다운이 남긴 정신적 상처.

가운 소매를 반듯하게 접는 손이 떨린다. 알림이 여섯 번 겹치자 그는 모니터를 뒤집지만 유리 반사에 파형이 남는다. **왕먀오:** “오늘은 여기까지.” (subtext: 돌아오지 않겠다는 선언을 스스로 믿고 싶다.)

### Scene 3: 살아 있는 거짓말
- **페이지:** p3 (1p) / **장소:** 같은 연구실 / **시간:** 새벽 / **날씨:** 잔비 / **등장인물:** 왕먀오, 스치친
- **장면 목적:** Theme Stated와 협업 시작. **Gap:** 스치친은 위로하려 옴 → 왕먀오가 표본을 요구하며 다시 일함.
- **감정 곡선:** 방어 → 신경질 → 작은 각성. **독자 감정:** 거친 농담 뒤의 돌봄.
- **연출 메모:** 스치친의 헝클어진 머리·수염·좁은 눈·올리브 재킷·담배. 담뱃불 주황을 청색 모니터에 맞댄다. 자료를 가린 커피잔이 Pope in the Pool의 움직임. Masking 사용. 매력 지수: 거칠지만 주인공을 포기하지 않는 직감. 게임/VR 아님.
- **가설 태그:** H2-emotion, H6-1. **개념 세팅:** ‘거짓말의 지문’을 읽는 수사 방법.

스치친이 커피잔을 내려놓아 파형 일부가 가려진다. 왕먀오가 잔을 밀자 같은 결이 드러난다. **스치친:** “죽은 자는 거짓말을 안 해. 지금 가속기는 거짓말을 하고 있어. 거짓말하는 놈은 진실을 알고 있어.” (subtext: 자네도 아직 끝나지 않았어.) **왕먀오:** “그럼 그놈이 남긴 지문부터 줘요.” (subtext: 도와달라.)

### Scene 4: 폐기 서식
- **페이지:** p4 (1p) / **장소:** 연구실 자료 벽 / **시간:** 아침 / **날씨:** 잔비 / **등장인물:** 왕먀오, 스치친
- **장면 목적:** 40년 기록과 리포트 형식 선행 세팅. **Gap:** 오래된 오염 기록을 버리려 함 → 동일 결을 시간 순서로 배열.
- **감정 곡선:** 냉소 → 집중 → 불안한 기대. **독자 감정:** 퍼즐이 맞기 시작함.
- **연출 메모:** 벽면 파일은 커다란 색 블록, 빨간 실 대신 파형의 동일한 톱니. 화면 속 폐기 서식 “오류 보고 / 제출처” 칸은 후처리. 종이 넘김과 떨어지는 클립으로 설명을 움직이는 Pope in the Pool. Masking 사용. 게임/VR 아님.
- **가설 태그:** H2-science, H6-2. **개념 세팅:** 버그 리포트 양식, 오류의 시간 표본.

왕먀오가 폐기 도장을 든 채 서식을 본다. 도장 아래의 톱니가 다른 해의 파형에도 있다. **왕먀오:** “쓰레기라면, 왜 같은 자리에 모였죠?” (subtext: 버렸던 판단이 틀렸을까 두렵다.)

### Scene 5: 안경에 남은 결
- **페이지:** p5 (1p) / **장소:** 그래프 투사 벽 / **시간:** 아침 / **날씨:** 잔비 그침 / **등장인물:** 왕먀오, 스치친
- **장면 목적:** 역설의 가시화. **Gap:** 위조는 이론보다 조악할 것 → 위조가 더 매끈함.
- **감정 곡선:** 확인 → 놀람 → 경악. **독자 감정:** 과학적 불가능을 눈으로 봄.
- **연출 메모:** 이론 곡선은 청색의 미세한 흔들림, 위조는 얇고 매끈한 신호 빨강. 안경 흰 반사 사이에 작은 간격이 ‘결’로 남는다. 시선·손끝을 클로즈업. Masking 강하게. 게임/VR 아님.
- **가설 태그:** H2-science, H5-impact, H6-2. **개념 세팅:** 위조가 예측보다 매끈하다는 역설.

왕먀오가 두 슬라이드를 포개자 이론선의 잔떨림 위로 위조선이 지나간다. 안경에 둘 사이 작은 결이 남는다. **왕먀오:** “더 잘 흉내 낸 게 아니야. 우리가 빠뜨린 걸 메웠어.” (subtext: 자신이 믿은 물리학에 구멍이 있음을 인정하기 싫다.)

### Scene 6: 움직이는 모형
- **페이지:** p6 (1p) / **장소:** 연구실 / **시간:** 오전 / **날씨:** 흐림 / **등장인물:** 왕먀오, 스치친
- **장면 목적:** 살아 있는 시뮬레이션과 입력 가능한 질문의 발상. **Gap:** 고정된 복사본이라 가정 → 시간별 결이 움직이는 걸 발견.
- **감정 곡선:** 들뜸 → 검토 → 경계. **독자 감정:** 희망과 불신의 동시 작동.
- **연출 메모:** 시간축을 카드 네 장으로 돌려 보여 주고 스치친이 한 장을 손가락으로 멈춘다. 청색에서 호박색으로 작은 전환. Pope in the Pool: 식은 커피를 쏟지 않으려 받치는 동작 사이 설명. Masking 사용. 게임/VR 아님.
- **가설 태그:** H2-science, H6-2. **개념 세팅:** 살아 있는 시뮬레이션, 상대 출력에 질문을 남기는 버그 리포트.

왕먀오가 카드 순서를 바꾸면 톱니의 높이가 조금씩 변한다. **왕먀오:** “복사본이면 왜 매번 손을 고치죠?” (subtext: 상대가 실수할 수 있기를 바란다.) **스치친:** “그럼 다음엔 우리가 묻는 차례겠네.” (subtext: 자네가 다시 일할 이유를 찾았어.)

### Scene 7: 가짜 승리
- **페이지:** p7 (1p) / **장소:** 연구실 자료 벽 / **시간:** 낮 / **날씨:** 흐림 / **등장인물:** 왕먀오, 스치친
- **장면 목적:** Midpoint false victory. **Gap:** 왕먀오는 증명했다고 여김 → 스치친의 검증 질문에 빈칸을 봄.
- **감정 곡선:** 고양 → 선언 → 균열. **독자 감정:** 발견의 쾌감과 불안.
- **연출 메모:** 만화적인 큰 흰 플래시와 붉은 곡선, 다음 컷은 조그만 빈 검증 칸. 시선이 올라갔다 내려오는 카메라. Masking 사용. 매력 지수: 스치친의 질문이 파트너를 보호한다. 게임/VR 아님.
- **가설 태그:** H2-science, H5-impact, H6-3. **개념 세팅:** 증거와 가설의 차이.

왕먀오가 자료 벽 중앙에 원을 친다. **왕먀오:** “위조 데이터 자체가 새 물리학의 증거다.” **스치친:** “법정에 내면, 누가 재현하지?” (subtext: 자네를 다시 무너뜨리고 싶지 않다.) 왕먀오의 펜촉이 공중에 멈춘다.

### Scene 8: 오염의 빈자리
- **페이지:** p8 (1p) / **장소:** 연구실 / **시간:** 낮 / **날씨:** 흐림 / **등장인물:** 왕먀오
- **장면 목적:** 가짜 승리를 꺼뜨리고 Moral Need를 드러냄. **Gap:** 결론을 지키려 함 → 오염 표본 앞에 펜을 내려놓음.
- **감정 곡선:** 방어 → 수치 → 침묵. **독자 감정:** 과학자가 느끼는 자기 불신.
- **연출 메모:** **무대사·무자막 풀페이지.** 작은 왕먀오, 큰 빈 벽, ‘오염’ 표시는 글자 대신 붉은 스탬프 형태만 그림에 두고 후처리. 청회색 바닥에 검은 그림자. Masking 사용. 게임/VR 아님.
- **가설 태그:** H2-emotion, H5-silence, H6-1. **개념 세팅:** 검증 가능한 독립 표본의 필요.

왕먀오가 열린 손으로 보고서를 누른다. 한 장이 미끄러져 빈 검증 칸이 드러난다. 그는 펜을 놓는다. 완전한 침묵.

### Scene 9: 게임의 오래된 질문창
- **페이지:** p9 (1p) / **장소:** 연구실 게임 로그 화면 / **시간:** 저녁 / **날씨:** 흐림 / **등장인물:** 왕먀오, 스치친
- **장면 목적:** 삼체 게임을 독립 대조 자료로 다시 사용. **Gap:** 게임은 별개라 여김 → 물리 버그의 톱니를 발견.
- **감정 곡선:** 회의 → 주목 → 탐색. **독자 감정:** 익숙한 세계의 새 용도.
- **연출 메모:** 현실 화면은 청회색, 게임 로그는 노랑·빨강의 선명한 셀 채색. 둥근 행성 UI, 가파른 원근, 화면 가장자리만 프레임을 살짝 침범. 문명 흥망은 로그의 세 칸 아이콘(건설→붕괴→재시작)으로 압축하며 새 게임 사건을 만들지 않는다. 빈 “디버거 질문” UI는 텍스트 후처리. Masking 사용.
- **가설 태그:** H2-science, H6-2. **개념 세팅:** 디버거 프롬프트의 빈 질문창, 게임 물리 버그.

스치친이 오래된 게임 저장 장치를 책상으로 민다. **스치친:** “놀이판에도 거짓말이 남나?” (subtext: 모르는 분야지만 자네 방법을 믿는다.) 왕먀오가 문명 반복 로그의 한 톱니에서 멈춘다.

### Scene 10: 두 세계의 한 지문
- **페이지:** p10 (1p) / **장소:** 이중 화면 앞 / **시간:** 저녁 / **날씨:** 흐림 / **등장인물:** 왕먀오, 스치친
- **장면 목적:** 게임 버그와 가속기 오차의 동일 위치·방향 확인. **Gap:** 닮은 모양 정도일 것 → 좌표를 정렬해도 정확히 겹침.
- **감정 곡선:** 검산 → 불신 → 전율. **독자 감정:** 퍼즐 결합의 쾌감.
- **연출 메모:** 양쪽 화면을 접는 책장처럼 중앙에서 만나게 한다. 동일 톱니는 신호 빨강, 인물의 둥근 얼굴은 가장자리. 한글 라벨·좌표는 후처리. Masking 사용. 게임 시각화는 p9의 노랑 UI를 현실 청색 선과 겹쳐 색 차이를 유지.
- **가설 태그:** H2-science, H5-impact, H6-3. **개념 세팅:** 동일성은 강한 단서이나 원인의 확증은 아님.

왕먀오가 한 화면을 반투명하게 넘긴다. 두 톱니가 정확히 한 점이 된다. **왕먀오:** “여기도 그 손이 닿았어.” (subtext: 적이 게임 안에서도 우리와 있었음을 두려워한다.)

### Scene 11: 기억의 재분류
- **페이지:** p11 (1p) / **장소:** 연구실, 기록 몽타주 / **시간:** 밤 / **날씨:** 맑음 / **등장인물:** 왕먀오, 기록 속 인물 실루엣
- **장면 목적:** EP003~005의 카운트다운·게임·소페르를 테스트 가설로 재독. **Gap:** 일방적 위협의 기억 → 반응을 읽은 보정 과정일 수 있음.
- **감정 곡선:** 공포 회상 → 연결 → 조심스런 추론. **독자 감정:** 과거 컷을 다시 보고 싶어짐.
- **연출 메모:** 4개의 명확한 칸, 숫자 카운트다운→게임 문명 반복→EP005 ‘버그’의 그림자→왕먀오의 현재 눈. 원본 컷 복제 대신 상징 실루엣. 청색/신호 빨강, 검은 그림자. Masking 사용. 게임은 기존 문명 아이콘을 노랑 셀 채색으로 잠깐 회상.
- **가설 태그:** H2-science, H6-2. **개념 세팅:** “카운트다운=강제 반응 테스트”는 아직 가설.

왕먀오가 세 기록에 같은 화살표를 그렸다가 마지막 화살표 끝에 물음표를 단다. **왕먀오:** “우릴 겁준 다음, 뭘 봤을까?” (subtext: 자신의 공포까지 표본이었다는 수치와 분노.)

### Scene 12: 다시 뜬 숫자
- **페이지:** p12 (1p) / **장소:** 빈 연구실 / **시간:** 밤 / **날씨:** 맑음 / **등장인물:** 왕먀오, 소페르의 시야 개입
- **장면 목적:** All Is Lost의 시작. **Gap:** 혼자 조용히 검증할 것 → 소페르가 바로 앞에 있음.
- **감정 곡선:** 집중 → 경직 → 공포. **독자 감정:** 피할 곳 없는 감시.
- **연출 메모:** 숫자는 망막 시야에만 후처리. 안경 바깥 풍경에는 숫자를 넣지 않는다. 눈동자, 굳은 입술, 펼쳤다 움켜쥔 손을 3컷으로 축소. 스탠드의 따뜻한 빛이 검은 그림자에 잠김. Masking 사용. 소페르 매력 지수: 말없이 먼저 반응하는 지능의 섬뜩함. 게임/VR 아님.
- **가설 태그:** H2-emotion, H6-3. **개념 세팅:** 기존 카운트다운 문법 재현.

왕먀오가 종이 위 질문 부호를 그리자 숫자가 돌아온다. 그는 눈을 감아도 시야 안쪽의 빛에서 벗어나지 못한다. **왕먀오:** “또 나를 보고 있군.” (subtext: 이제는 나도 너를 봤다.)

### Scene 13: 질문으로 바뀐 계기판
- **페이지:** p13 (1p) / **장소:** 왕먀오의 망막 시야 / **시간:** 밤 / **날씨:** 해당 없음 / **등장인물:** 왕먀오, 소페르
- **장면 목적:** All Is Lost와 의문의 전환. **Gap:** 숫자가 이어질 줄 앎 → 디버거 프롬프트 “왜 알아차렸나?”가 나타남.
- **감정 곡선:** 위축 → 정지 → 전율. **독자 감정:** 감시자가 질문을 한다는 공포.
- **연출 메모:** 풀페이지. 큰 뿔테 렌즈의 흰 반사 가운데 아주 작은 왕먀오, 숫자가 지워진 자리에 빈 사각 UI와 후처리 질문. 검은 그림자·신호 빨강 최소 사용. 위협받는 과학자의 죽은 듯한 정적으로 **whiff of death**. Masking 강하게. 소페르 매력 지수: 반응의 짧음이 오히려 지성의 크기를 암시. 게임 UI의 p9 빈 질문창과 형태를 맞춘다.
- **가설 태그:** H5-impact, H6-3. **개념 세팅:** 디버거 프롬프트가 현실로 침입.

숫자들이 하나씩 사라진다. 같은 자리에 질문창이 켜진다. **소페르(시야 텍스트):** “왜 알아차렸나?” 왕먀오의 입은 반쯤 벌어졌지만 말은 나오지 않는다.

### Scene 14: 대답 대신 질문
- **페이지:** p14 (1p) / **장소:** 연구실 책상 / **시간:** 밤 / **날씨:** 맑음 / **등장인물:** 왕먀오
- **장면 목적:** Self-Revelation과 Act 3 진입. **Gap:** 적에게 대답해야 산다고 느낌 → 반증 가능한 질문을 쓰기로 함.
- **감정 곡선:** 공포 → 사고 → 조용한 결의. **독자 감정:** 작지만 정확한 용기.
- **연출 메모:** 눈 초점이 돌아오고, 손끝의 떨림이 직선으로 수렴한다. 청회색에 호박색 스탠드가 회복. p14-3은 무대사 여백 컷. Masking 사용. 왕먀오 매력 지수: 확신을 내려놓고 검증을 선택하는 지적 용기. 게임/VR 아님.
- **가설 태그:** H2-emotion, H5-silence, H6-2. **개념 세팅:** 보고서의 질문·재현 조건·제출처.

왕먀오가 ‘증거’라고 쓴 말을 한 줄로 긋고 옆에 ‘가설’을 적는다. **왕먀오:** “관측당하는 것도 관측이다.” (subtext: 너만 나를 읽는 게 아니다.) **왕먀오:** “대답은 나중에.” (subtext: 우선 네 반응을 측정하겠다.)

### Scene 15: 첫 버그 리포트
- **페이지:** p15 (1p) / **장소:** 연구실 책상, 노트 극클로즈업 / **시간:** 밤 / **날씨:** 맑음 / **등장인물:** 왕먀오의 손
- **장면 목적:** 첫 행위와 다음 화의 질문을 동시에 남김. **Gap:** 보낼 곳 없는 생각 → 서명한 보고서가 완성되지만 제출처는 비어 있음.
- **감정 곡선:** 정돈 → 실천 → 열린 불안. **독자 감정:** 한 페이지의 용기와 수신자의 의문.
- **연출 메모:** 풀페이지. 큰 노트, 작은 손, 안경에 비친 결의 축소판. 검은 잉크선과 밝은 종이, 빨간 오차 선 하나. 제목·문장·서명·제출처는 후처리. Masking은 인물 부재와 도표의 정밀함으로 처리. 게임/VR 아님.
- **가설 태그:** H1-strong, H5-impact, H6-3. **개념 세팅:** p4 양식의 실현; 제출처의 빈칸은 의도적 미해결.

왕먀오가 여섯 지문을 한 줄에 그리고 제목을 적는다. **왕먀오(노트):** “실험은 못 한다. 하지만 적의 거짓말을 실험 장치로 쓸 수 있다.” 아래에는 **왕먀오** 서명, 그 밑 **제출처: ______**. 손이 빈칸 위에서 멈춘다.
