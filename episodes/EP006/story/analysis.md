# EP006 원작 분석 — S2E01 「오차의 결」 (v3)

## 로그라인
EP005의 함대를 보고 연구를 포기한 왕먀오는 6대륙 가속기의 똑같은 거짓말을 추적하다, 적의 위조가 인간 이론보다 더 매끈하다는 역설을 발견한다. 실험할 수 없는 과학자가 적의 거짓말로 첫 실험을 설계한다는 아이러니를, 안경 렌즈에 걸린 작은 오차의 결과 빈 제출처가 남은 버그 리포트로 보여 준다. 과학 미스터리를 좋아하는 신규 독자와 파일럿의 단서를 다시 읽고 싶은 독자가 대상이다.

## 테마
- 관찰은 중립이 아니다. 관측당하는 사람도 관측자를 읽을 수 있다.
- 실험 장치를 빼앗겨도 사고와 검증의 책임은 남는다.

## 가설
- 주 가설: **H6 미스터리 강도** — 같은 지문 → 매끈함 → 게임 일치 → 질문으로 강도를 단계적으로 높인다. 독자의 페이지별 이탈·되돌아보기율을 본다.
- 부 가설: **H5 임팩트/침묵 교차** — p1 충격, p8 무대사 정지, p10 일치, p13 질문, p15 작성의 체류시간을 비교한다.
- 보조 변수: **H2 감정/과학 배분**은 p2·3·8·12·14 대 p4~7·9~11의 체류를, **H1 클리프행거**는 p14 중강도에서 p15 강도로 상승시킨 뒤 다음 화 복귀율을 본다.

**원작 독립적 재해석 (PRD S6): 예.** 원작의 소페르 물리학 봉쇄·왕먀오의 상처·삼체 게임을 계승하되, “학습하는 위조 시뮬레이터”와 “버그 리포트”는 이 각색이 만든 독립적 추론 축이다. 이번 화에서 확증하는 것은 출력 지문의 일치이며, 위조가 새 물리학을 완전히 증명한다는 명제는 p7의 가짜 승리로 남긴다.

## 연속성·시각 기준
- EP005의 함대 출항과 왕먀오의 정신적 상처 직후. 카운트다운, 소페르, 삼체 게임은 이미 알려진 현상으로 사용한다. EP005에서 카운트다운은 연구 중단 압박으로 제시되었으므로 여기서 “테스트”는 새 가설이며 확정 사실로 말하지 않는다.
- 왕먀오: 30대, 단정한 검은 머리, 큰 뿔테 안경, 마른 체형, 청회색 셔츠. 스치친: 40대, 헝클어진 머리·수염·좁고 피곤한 눈, 묵직한 몸, 낡은 올리브 재킷, 담배. 소페르는 육체보다 시야의 개입으로 표현한다.
- 모든 이미지 지시는 **STYLE_BLOCK**을 프롬프트 맨 앞에 둔다: “Bold clean ink linework, flat vibrant cell-shaded colors, rounded expressive character designs, dramatic but playful composition, distinctive 1980s Akira Toriyama manga aesthetic. Simple but expressive backgrounds with bold black shadows. Clean panel borders, dynamic perspective.” 한글·숫자·그래프 라벨은 후처리 텍스트로 둔다.
