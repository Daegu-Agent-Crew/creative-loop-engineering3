# EP009 「게임은 QA였다」 — 구조 설계 (15p)

## 3막과 콜드 오픈

| 막 | 페이지 | 역할 |
|---|---|---|
| 1 설정 | 1~4 | 192호의 뒤집힌 그림자→현재 복귀→숨은 분기 발견 |
| 2 갈등 | 5~11 | EP003~004 게임 로그와 40년 보존 표본 대조, 위조 출력과 유사한 보정 순서 발견, 균열의 위험 |
| 3 해결/훅 | 12~15 | 연결된 복제본의 증거 삭제→오프라인 재현→세 경계 시험 카드 |

첫 컷은 종료된 게임 폐허에서 그림자만 되감기는 부조화다. 첫 세 컷은 p1의 되감김, p2 현재의 톱니 파형, 스치친의 “게임에도 묻었겠지”로 미스터리와 시간선 복귀를 동시에 만든다. 무언 풀페이지는 p1·7·11·15. 이미지에는 한글·숫자·코드를 넣지 않는다.

|---|---|---|

## 미스터리와 실험 변수

| 계층 | 단서 | 배치 / 회수 |
|---|---|---|
| 씨앗 | 이중 그림자, 종료 뒤 표시등 | p1·3 → p4·10 |
| 장막 | 문명 192호 표면 엔딩 아래 캐시 | p4 → p10 |
| 전환 | 원인보다 먼저 보정되는 결과 | p10 → p13 재현 |
| 잔여 질문 | 게임 시제품의 경계가 실전 위조 엔진에도 남았는가 | p14~15 → EP010 |

H6 미스터리 강도 1~3은 위 페이지 표에 명시했다. H5의 압도/여백은 p1·7·11·15와 인접 다컷 페이지를 교차한다. H2는 과학 설명 p4~10, 증거 상실과 협업 p12~13으로 나눈다. H1은 p15의 검증 전 질문으로 강한 다음 화 약속을 만든다. 첫 컷과 마지막 컷은 모두 그림자 경계이지만, 마지막에는 인간이 선택한 입력 카드가 전경에 있다.
