# EP007 장면 작성 — 「적의 실험 장치」

공통 연출: 굵고 깨끗한 잉크 선, 선명한 셀 채색, 둥근 얼굴과 검은 그림자. PDC 회의장의 차가운 청회색과 연구실의 호박색 조명을 교차한다. 모든 도표·문서·장비 화면은 **문자 없는 형태**로 촬영하고 한국어·숫자는 SVG 후처리한다. 왕머여는 EP006의 왕먀오와 동일 인물. 무대사 풀페이지 p1·p8·p13·p15.

### Scene 1: 빈 제출처의 행선지 — p1
- **장소/시간/등장:** PDC 회의장, 오전 / 왕머여·스치친·검증위원.
- **목적/Gap:** 개인 노트를 건네면 검토가 시작될 것 → 여섯 관제 화면이 가려진 공식 심문 무대가 됨.
- **감정:** 결심→긴장. **연출:** 봉투와 가린 화면을 원근으로 맞춘 청회색 풀페이지, 인물은 작게. **태그:** H5-silence, H6-2.

### Scene 2: 거절의 첫 문장 — p2
- **장소/시간/등장:** 같은 회의장, 오전 / 세 인물.
- **목적/Gap:** 지문을 보여주면 동의 → 오염 데이터라며 기각. **감정:** 기대→굴욕→집중.
- **대사:** 검증위원 “오염된 데이터로 무슨 물리학을 합니까.” 스치친 “거짓말도 입을 맞추려면 시간이 걸려.” (subtext: 반박 속에 시험 방법이 있다.)
- **연출:** 도장 손의 큰 그림자, 왕머여의 뿔테 반사. 스치친은 담배를 입에 물지 않고 손가락 사이에서 굴린다. **태그:** H2-emotion, H6-2.

### Scene 3: 결과가 아니라 반응 — p3
- **목적/Gap:** 아름다운 위조 곡선으로 설득 → 결과값이 불신받자 입력과 출력 사이의 변화를 제안.
- **감정:** 방어→정확함. **대사:** 왕머여 “그 값은 믿지 않습니다. 바뀌는 순서를 보자는 겁니다.” (subtext: 자신의 전편 확신을 내려놓는다.) 위원 “먼저 틀릴 조건부터 쓰십시오.”
- **연출:** 빨간 출력선과 파란 입력선을 다른 레이어로 분리. **태그:** H2-science, H6-2. **개념:** 입력 교란과 시간 순서.

### Scene 4: 실패할 자격 — p4
- **목적/Gap:** 위원의 요구는 방해 → 무교란 대조도 변하면 철회한다는 조건을 쓰며 가설이 강화됨.
- **감정:** 수치심→결심. **대사:** 왕머여 “대조군도 따라 움직이면, 제 보고서는 찢으십시오.” (subtext: 자기 명예보다 검증을 택한다.) 스치친 “찢기 전에 사본은 남깁시다.” (subtext: 실패도 증거다.)
- **연출:** 빈 실패 기준 칸에 펜이 닿는 손 극근접. **태그:** H2-emotion, H6-1.

### Scene 5: 여섯 개의 흠 — p5
- **목적/Gap:** 동일한 오차를 주려 함 → 스치친이 동일 지문은 누설·공통 오류와 구별하기 어렵다고 지적, 시설별 다른 도형을 선택.
- **감정:** 놀이 같은 집중→불길한 재미. **대사:** 스치친 “도둑 잡는데 같은 신발 여섯 켤레를 깔아두진 않아.” (subtext: 나도 이 실험의 동료다.) 왕머여 “모양도, 시각도 나눕니다.”
- **연출:** 삼각·계단·갈고리 등 문자 없는 오차 카드. 과학 도표를 손으로 배열하는 액션. **태그:** H2-science, H6-2. **개념:** 지문과 교란 분리.

### Scene 6: 봉인 — p6
- **목적/Gap:** 동시 전송만 하면 됨 → 독립 시계·봉인 봉투·무교란 대조가 필요함을 확인.
- **감정:** 조급함→절차의 안정. **대사:** 왕머여 “대조 장비엔 손대지 마세요.” 스치친 “이쪽 봉투는 내 손이 더러워도 안 열지.” (subtext: 자신이 보존을 책임진다.)
- **연출:** 스치친의 거친 손과 섬세한 봉인 대비. **태그:** H2-science, H6-2. **개념:** 대조군·사전 등록·독립 타임스탬프.

### Scene 7: 허가와 첫 입력 — p7
- **목적/Gap:** 승인되면 증명 완료 → 첫 변화가 보여도 원인 미확정.
- **감정:** 압박→짧은 환호. **대사:** 위원 “한 번입니다.” 왕머여 “한 번이면 순서는 볼 수 있습니다.” (subtext: 기회가 적다는 두려움을 감춘다.)
- **연출:** 여섯 손가락이 다른 키 위에 떠 있고 입력선만 먼저 꺾인다. **태그:** H5-impact, H6-3.

### Scene 8: 빈 시간 — p8
- **목적/Gap:** 즉시 응답 예상 → 아무것도 일어나지 않음.
- **감정:** 기대→불안. **연출:** 텅 빈 관제실의 여섯 모니터, 아주 작은 인물들, 움직이지 않는 선. 무대사·무자막 풀페이지. **태그:** H5-silence, H6-1.

### Scene 9: 너무 매끈한 복구 — p9
- **목적/Gap:** 교란이 오래 남아야 흔적 → 빨간 출력선이 금세 매끈해져 증거를 지우는 듯함.
- **감정:** 환호→상실. **대사:** 위원 “돌아왔군요. 원래대로.” 왕머여 “너무 빨리요.” (subtext: 실패 속에서 새 측정치를 발견한다.)
- **연출:** 급히 가늘어지는 신호 빨강, 손을 놓는 연구원. **태그:** H2-emotion, H6-3.

### Scene 10: 회복의 모양 — p10
- **목적/Gap:** 모든 장비가 같은 장애를 겪었을 것 → 각자 심은 도형 순서대로 다른 지연과 정밀도 변화.
- **감정:** 의혹→전율. **대사:** 왕머여 “계단은 계단 뒤에, 갈고리는 갈고리 뒤에 바뀌었습니다.” (subtext: 적이 각각을 읽었다.) 스치친 “발자국을 지우면서 새 발자국을 찍었네.”
- **연출:** 여섯 스트립을 시간축에 펼쳐 빨간 후행 변화를 대응. **태그:** H5-impact, H6-3.

### Scene 11: 공통 오류의 그림자 — p11
- **목적/Gap:** 곧 발표 가능 → 위원이 공통 장비 오류를 제기해 결론 보류.
- **감정:** 들뜸→자기 검열. **대사:** 위원 “같은 계통의 장비라면?” 왕머여 “그래서 손대지 않은 선이 있습니다.” (subtext: 나도 그 가능성을 두려워했다.)
- **연출:** 왕머여가 결론 문장을 가로 긋고 봉인된 대조 카드를 펼친다. **태그:** H2-emotion, H6-2.

### Scene 12: 대조선 — p12
- **목적/Gap:** 대조군도 흔들릴 것 → 봉인 장비는 고정, 변화는 각 입력 뒤에만 일어남.
- **감정:** 긴장→조심스런 확신. **대사:** 왕머여 “입력 전엔 없고, 대조에는 없습니다.” 위원 “그럼 이건 물리학의 값이 아니군요.” 왕머여 “거짓말의 반응 시간입니다.”
- **연출:** 여섯 흔들리는 출력과 한 줄의 평평한 대조선. **태그:** H2-science, H6-3.

### Scene 13: 다른 박자 — p13
- **목적/Gap:** 적은 한 번에 똑같이 덮을 것 → 시설별 보정이 각기 다른 박자로 수렴.
- **감정:** 승리감→낯선 공포. **연출:** 모니터 여섯 개를 한 장의 악보처럼, 지문 뒤에 늦게 오는 그림자 파형. 인물의 눈은 작게 반사된다. 무대사·무자막 풀페이지. **태그:** H5-silence, H6-3.

### Scene 14: 제한된 문장 — p14
- **목적/Gap:** 학습을 증명했다고 외칠 것 → 위원이 재현을 요구하고 왕머여가 관측한 범위만 쓴다.
- **감정:** 고양→절제→새 긴장. **대사:** 위원 “한 번으로는 결재할 수 없습니다.” 스치친 “그럼 두 번째 신발을 놓죠.” 왕머여 “감시자는 입력마다 보정했습니다. 내부가 어떻게 생겼는지는 아직 모릅니다.”
- **연출:** 결론 문서의 짧은 한 줄과 길게 비어 있는 다음 실험 칸. **태그:** H1-build, H2-mixed, H6-2.

### Scene 15: 보는 눈 — p15
- **목적/Gap:** 인간이 적을 관측하는 도구를 얻음 → 그 도구를 통해 적도 인간의 선택을 학습할 수 있음을 암시.
- **감정:** 성취→다음 화의 불안. **연출:** p1에서 천으로 가렸던 여섯 화면이 열려, 각각의 지문이 하나의 거대한 눈 윤곽처럼 배열된다. 인물 둘은 그 앞에 아주 작다. 실제 눈·소페르 본체를 단정해 그리지 않는다. 무대사·무자막 풀페이지. **태그:** H1-cliffhanger, H5-silence, H6-3.
