# CLE3 Storyboards

EP003~005 스토리보드 콘티 — 에피소드당 1장 요약

## 구조

```
storyboards/
├── text/          # 텍스트 콘티 (대사 + 연출 메모 중심)
│   ├── EP003.html / .png   — "세 개의 태양"
│   ├── EP004.html / .png   — "문명의 역사"
│   └── EP005.html / .png   — "별의 바다"
├── image/         # 이미지 콘티 (AI 생성 장면 + 대사 오버레이)
│   ├── EP003-image.html / .png
│   ├── EP004-image.html / .png
│   └── EP005-image.html / .png
└── scenes/        # 개별 AI 생성 장면 이미지
    ├── EP003_scene1~4.jpg
    ├── EP004_scene1.jpg
    └── EP005_scene1~4.jpg
```

## 콘티 구성 (에피소드당)
