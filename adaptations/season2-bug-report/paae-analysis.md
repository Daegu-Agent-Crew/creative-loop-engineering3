- **스킬:** story-adaptation (proposal `story-adaptation-20260816-e4885d508e`, 승인 대기)
- **원작:** 류츠신 『삼체』 1부 + CLE3 파일럿(EP001~005) 스코프
- **각색 축:** 원작 DNA 보존 × 잠재공간 탐색 × 예상 파괴 × 후향적 필연성

## 1. PAAE 시트

### Preserve — 절대 잃지 않을 원작 DNA (5)
1. **"우주의 법칙이라 믿었던 것이 누군가에 의해 조작될 수 있다"는 공포** (소페르 물리학 봉쇄)
2. **40년 전 인간의 손으로 시작된 죄** — 청신(예원제)의 송신, 공유 불가능한 책임
3. **절대 강자 앞에서 비정상적으로 보이는 논리** — ETO의 허무, 인류 배신의 심리
4. **문명의 반복을 게임으로 체험하는 구조** — 삼체 게임의 중독성과 학습성
5. **"너희는 벌레다. 그러나 벌레는 죽지 않는다"** — 절망 안의 역전 가능성

### Approach — 2~3배 증폭할 것
- 원작은 "물리학이 죽었다"(가속기 위조)를 **부정적 종말**로만 쓴다.
- → 각색에서는 **뒤집는다: 물리학은 죽은 것이 아니라, 적의 손에서 살아서 진화하고 있다.**
- 위조 데이터 자체가 인류 역사상 가장 거대한 물리학 데이터셋이라는 역설을 시즌 전체 엔진으로 증폭.

### Avoid — 회피할 예상 전개
- ❌ 왕먀오가 절망 → 비밀결사 조사 → 사선(史强)과 추격전 (파일럿 예상 연장선)
- ❌ 소페르를 단순 '완벽한 감시자/악당'으로 유지
- ❌ "인류, 마지막 희망의 무기를 개발한다"식 저항 서사
- ✅ 변형 원칙: **결과는 유지(물리학 봉쇄 유지), 도달 과정은 예상 밖**(봉쇄 자체가 역이용당한다)

### Explore — 잠재공간 탐색 (최강 동기)
핵심 발견: **소페르의 위조는 '정지된 거짓'이 아니라 '살아있는 시뮬레이션'이다.**
시뮬레이션은 40년간 관측자(인간)의 반응 데이터로 보정되어 왔다.
→ 인류는 실험을 잃은 것이 아니라, **적의 시뮬레이터를 실험 장치로 쓸 기회**를 얻었다.

## 4. 인과 다이어그램

**파일럿에서 독자가 믿는 인과:**

```
청신의 송신 → 소페르 감시 개시 → 카운트다운(위협) + 가속기 위조(물리학의 죽음) → 인류 절망
```

**각색의 실제 인과 (숨겨진 X):**

```
X = 소페르의 위조는 살아있는 시뮬레이션이고,
    인간 관측자의 반응 데이터로 40년간 보정(학습)되어 왔다.

        X ──→ 카운트다운/눈/꿈  (A: 독자는 '위협'으로 이해)
        │
        └──→ 가속기 위조 데이터  (B: 독자는 '물리학의 죽음'으로 이해)

A와 B는 인과가 아니라, 같은 학습 루프의 두 출력이다. (A ← X → B)
```

- 소페르가 위조 데이터를 '그럴듯하게' 만들려면 인류 물리학의 모형이 필요하고,
  그 모형의 정밀도를 맞추려면 관측자(인간)의 반응을 수집해야 했다.
- **카운트다운은 위협이 아니라 강제 회귀 테스트였다. 왕먀오는 위협받은 것이 아니라 테스트 케이스 1번이었다.**
- 그리고 시뮬레이션이 살아있다는 것은 — **시뮬레이션에 입력을 넣을 수 있다는 뜻이다.**
